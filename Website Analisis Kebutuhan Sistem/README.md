# SIKARA

Sistem Identifikasi Kebutuhan, Analisis, dan Rekomendasi Aplikasi Penjaminan Mutu Polibatam.

```bash
npm install        # pasang Tailwind CLI 
npm run setup      # pasang Flask
npm run dev        # jalankan di http://localhost:5000
```
